# עורך צנרת דו-ממדי (מבט על) – `editor.html`

עורך במבט על שעובד על אותם נתונים של המודל התלת-ממדי. כניסה: `editor.html` (או מהמודל: שכבות → אינסטלציה → "✏️ עורך צנרת דו-ממדי").

## מבנה הנתונים

| קובץ | תפקיד | נוצר ע"י |
|---|---|---|
| `data/plumbing/routes.json` | **מקור האמת** לתוואי ההצעה: קווים (`runs`) עם `vertices` = נקודות פנייה `[E, N, H]` ב-ITM, ‏H מוחלט; צמתים (`nodes`): נקודות צריכה, מחלקים, דודים; צירי הבית (`frame`); רשימת קווי היועץ שההצעה מחליפה (`superseded`). כל רשומה עם `source` ו-`status`. | זריעה חד-פעמית: `python3 tools/plumbing/seed_routes.py` (מ-`proposal.json`). מאז – רק העורך. הסקריפט מסרב לדרוס עריכות ידניות בלי `--force`. |
| `data/plumbing/network.json` | תוכנית היועץ – **קריאה בלבד** בעורך. | `tools/plumbing/extract.py` + `build.py` |
| `data/plumbing/plan-background.json` | רקע אדריכלי לכל קומה (קווים ב-ITM + טקסטים), מתוך הבלוקים של האדריכל ב-DXF של היועץ. | `python3 tools/plumbing/extract_plan_background.py` |
| `data/structure/*.json`, `data/architecture/blocks.json` | שלד לבדיקת התנגשויות: קירות ועמודי בטון, קורות מעל ומתחת, בלוקים, חומות, גבול מגרש. | צינור החילוץ של המודל |
| `data/config/plan-editor.json` | קבועי תצוגה בלבד: קומות, צבעים, עובי קו, רשת, הצמדה. | ידני |

`data/manifest.json` → `editorFiles`: הקבצים שרק העורך טוען (המודל לא טוען אותם עד שלב 4).

רשומת קו ב-`routes.json`:
```json
{ "id": "C-WC2@ground", "kind": "run", "system": "cold", "floor": "ground", "D_mm": 16, "material": "PEX",
  "from": "MAN-ground", "to": "WC2@ground", "vertices": [[179589.948, 576241.661, 280.95], "..."],
  "insulation_mm": null, "status": "proposal | manual", "source": "data/plumbing/proposal.json → runs C-WC2@ground",
  "simplify": { "tol_m": 0.01, "ptsBefore": 131, "ptsAfter": 31, "maxDev_m": 0.01 } }
```
מערכות: `cold`, `hot`, `return` (סחרור), `sewage`, `vent`, `rain`, `pumped`.

## שלב 1 – מה יש

- **קומות:** מרתף, קרקע + פיתוח, א', גג (מקשים 1–4). התוכנית מסובבת לצירי הבית; מצפן לצפון האמיתי; סרגל קנה מידה.
- **קו שעובר דרך הקומה** (קולטן, עולה): עיגול עם נקודה במרכז.
- **לחיצה** על קו או נקודה: מערכת, קוטר, חומר, מאיפה לאן, אורך במבט על ו-3D, מפלסים יחסית ל-±0.00, I.L ושיפוע, מקור.
- **הצמדה** (S): לפינות ולקווים של השלד, לנקודות הצנרת, לקירות הרקע; אחרת לרשת (1 / 5 / 10 / 50 ס"מ). שורת הסטטוס: x/y בצירי הבית + E/N.
- **טלפון:** גרירה באצבע אחת, צביטה להגדלה, הקשה לבחירה, השכבות במגירה (☰).
- בדיקה: `node tests/editor.mjs` (חלק מ-`npm test`). אימות: [docs/verification/editor-stage-1.md](../verification/editor-stage-1.md).

## שלב 2 – עריכה

- **בחירה (V):** לחיצה על קו של ההצעה מציגה ריבועים בנקודות הפנייה (ריבוע מלא = קטע אנכי) ואת כרטיס המאפיינים.
- **גרירת מקטע:** המקטע זז במקביל לעצמו, והשכנים מתארכים או מתקצרים. בקצה הקו (נקודת צריכה / מחלק) נוסף מקטע מחבר, כך שהקצה לא מתנתק.
- **גרירת ריבוע:** מזיז את הפינה. במצב אורתו (O) מקטע צמוד שהיה בצירים נשאר בצירים: פינה שכנה מחליקה, ובקצה הקו נוספת פינה.
- **הוספה / מחיקה:** לחיצה כפולה על מקטע מוסיפה פינה (בטלפון: לחיצה על מקטע → "＋ נקודה במקטע"). Delete או "− מחק נקודה" מוחקים. נקודה עם קטע אנכי לא נמחקת.
- **כרטיס:** מערכת, חומר וקוטר (מהקטלוג), מ / אל, הערה, הזזת גובה לכל הקו, גובה לנקודה. בביוב ובגשם: שיפוע % → "החל" (מחשב מפלסים מהקצה העליון) ו-"⇄ כיוון זרימה". "⟂ יישור לצירי הבית", "↺ החזר למקור", "🗑 מחק צינור". בקו של היועץ: "⧉ העתק להצעה" (מפלס = I.L + חצי קוטר חיצוני מהקטלוג).
- **צינור חדש (N):** מערכת, חומר, קוטר ומפלס בסרגל התחתון. לחיצה = נקודה (אורתו + הצמדה), לחיצה כפולה / Enter = סיום, Esc = ביטול. מזהה: `N-<מערכת><מספר>@<קומה>`.
- **ביטול / חזרה:** Ctrl+Z / Ctrl+Y (עד 200 צעדים, לסשן).
- **שמירה:** אוטומטית אחרי כל פעולה. מצב השמירה מוצג בסרגל העליון. קו שנערך מסומן בהילה סגולה ו-`status: manual` + `edited`.
- **קומה:** קו נערך רק בקומה שבה הוא מצויר במבט על. בקומות שהוא רק עובר בהן (קולטן) הוא מוצג ולא נערך.
- אימות: [docs/verification/editor-stage-2.md](../verification/editor-stage-2.md).

## שלב 3 – בדיקות

- רצות על כל קווי ההצעה בטעינה ואחרי כל שינוי (כ-0.1 ש'), ועל הקו הנגרר בזמן הגרירה.
- **⛔ שגיאה** – הקו נצבע באדום: חוצה עמוד, חוצה קורה (לפי טווח הגובה של הקורה), קטע אנכי בתוך בטון, שיפוע נגדי / עלייה בכיוון הזרימה.
- **⚠ אזהרה:** מעבר בקיר (בטון / בלוקים) לא בניצב, שיפוע מתחת לשיפוע התכנון, קצה לא מחובר, נקודת צריכה בלי קו מים קרים / חמים.
- **בפאנל:** "בדיקות בקומה" עם המספרים והרשימה; לחיצה על ממצא מתמקדת בו ובוחרת את הקו. בכרטיס הקו – הממצאים שלו.
- הסבולות ב-`data/config/plan-editor.json` → `checks`. אימות: [editor-stage-3.md](../verification/editor-stage-3.md); הממצאים בהצעה: [editor-stage-3-findings.md](../verification/editor-stage-3-findings.md).

## הזזת מחלק / נקודה כמערכת מחוברת (בקשת אביחי 09.11)

- בחירת מחלק (ריבוע שחור) ואז גרירה, או "הזזה בצירי הבית" בכרטיס: המחלק זז יחד עם כל צנרת המים (קרים, חמים, סחרור) שמתחילה או נגמרת בו, כפעולה אחת (ביטול אחד).
- מכל קו זזות הנקודות שבטווח `edit.manifoldZone_m` (0.6 מ') מהמחלק – היציאות והברזים. משם הקו נשאר מחובר: בקו ישר בצירי הבית נוסף מחבר L; בקו מעוגל ההזזה דועכת לאורך 0.6 מ' הבאים.
- נקודת צריכה / תא: אותו דבר, אבל רק קצה הצינור זז.
- עולים שעוברים ליד המחלק בפיר (סניקה, אוורור) לא נגררים איתו.
