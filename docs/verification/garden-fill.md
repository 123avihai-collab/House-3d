# אימות – הגינות: מילוי אדמה מקומית + מצע מהודק + דשא סינטטי (OC-17, 13.11.2026)

**ההוראות (אביחי, 13.11.2026):**
1. מילוי אדמה מקומית, ומעליו מצע מהודק 10 ס"מ שמגיע ל-2 ס"מ מתחת לגובה הריצוף.
2. אותו דבר בגינה שבחזית. ב-2 הס"מ ייכנס דשא סינטטי בעובי 3 ס"מ, שיבלוט 1 ס"מ מעל הריצוף, עם שכבה נפרדת שאפשר לכבות ולהדליק.

**השכבות, מלמטה למעלה:**
1. פני הקרקע אחרי החישוף ויישור המגרש (קיים)
2. **מילוי אדמה מקומית** עד תחתית המצע (עובי משתנה)
3. **מצע מהודק** 10 ס"מ – ראשו = פני הריצוף הצמוד − 0.02
4. **דשא סינטטי** 3 ס"מ – פניו = פני הריצוף הצמוד + 0.01

גובה הריצוף = המשטח בשיפוע של הרצפה החיצונית הצמודה (`data/finishes/tiling/exterior.json`), שממשיך אל הגינה.
