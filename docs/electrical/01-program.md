# חשמל – פרוגרמה ותוכנית עבודה (טיוטה 1, 10.11.2026)

**מצב:** טיוטה לדיון. אין תוכנית יועץ חשמל – התכנון נבנה כאן יחד עם אביחי.
כל ערך במסמך הוא **הנחת תכנון (provisional)** עד שאביחי מאשר אותו, ואף אחד מהם עוד לא נכנס למודל.

> **הסתייגות:** זהו תכנון מקדים לצורך תיאום עם השלד, כמויות והחלטות. הגשה לחברת החשמל, תכנון הלוחות הסופי, חתכי כבלים והארקת היסוד מחייבים חשמלאי בעל רישיון מתאים ובדיקת בודק מוסמך.

## 2. עומסים מקדמיים וגודל חיבור

ההספקים הם ערכים טיפוסיים, **לא נתוני יצרן**. הם נועדו רק לבחירה ראשונית של גודל החיבור ויתעדכנו כשייבחר ציוד.

|---|---|---|---|
| כיריים אינדוקציה | 7.4 | 3 | |
| תנור כפול | 7.0 | 1+1 | שני מעגלים |
| מדיח, מכונת כביסה, מייבש | 7.0 | 1 כל אחד | מעגל נפרד לכל מכשיר |

| עמדת טעינה | 11.0 | 3 | עם ניהול עומסים דינמי |
| משאבת חום לבריכה | 4.0 | 1 או 3 | |
| משאבות בריכה (סינון, בור איזון) | 2.0 | 1 | |
| משאבות ביוב PC-1, PS-1 | 2.0 | 1 | |
| תאורה ושקעים כלליים, בית | 6.0 | 1 | |

| **סה"כ מותקן** | **≈ 79** | | |

- ביקוש מרבי משוער במקדם ביקוש 0.45–0.5: **כ-35–40 kW**.
- חיבור 3×40A נותן כ-27.6 kVA, וחיבור 3×63A נותן כ-43.5 kVA.
- **המלצה מקדמית: חיבור 3×63A**, עם ניהול עומסים לעמדת הטעינה. חיבור 3×40A אפשרי רק עם השלת עומסים אגרסיבית (טעינה, חימום בריכה ודודים בלילה בלבד).
- גודל המערכת הסולארית מוגבל בגודל החיבור ובשטח הגג הפנוי (קולטים, דודים, מעבי מיזוג). ייקבע בפריסת הגג.

## 3. מבנה ההזנה והלוחות (הצעה)

```
רשת חברת החשמל
  └─ ארון מונה בפילר (מונה דו-כיווני, מא"ז ראשי)
       └─ קו הזנה תת-קרקעי בצינור, דרך שרוול בחומה ובקורת היסוד
            └─ לוח ראשי
                 ├─ לוח קומת קרקע (כולל מטבח)
                 ├─ לוח קומה א'
                 ├─ לוח גג (דודים, סחרור, מיזוג, ממיר סולארי)
                 ├─ לוח יחידה 1  ← מונה משנה
                 ├─ לוח יחידה 2  ← מונה משנה
                 ├─ לוח בריכה וחדר מכונות (ממסר פחת נפרד)
                 ├─ עמדת טעינה (מעגל ישיר + מד זרם לניהול עומסים)
                 └─ לוח פיתוח (תאורת גן, שער, השקיה, משאבות ביוב)
```

## 5. איך זה ייכנס למודל

אותה שיטה כמו באינסטלציה:
- נתונים ב-`data/electrical/` (לוחות, קווים, נקודות, שרוולים), כל ערך עם `source` ו-`status`.
- שכבה תלת-ממדית עם תגיות קומה / מערכת `electrical` / שלב בנייה.
- עריכת נקודות וקווים בעורך הדו-ממדי (`editor.html`).
- בדיקות אוטומטיות: התנגשות עם שלד ואינסטלציה, מעבר בממ"ד רק בשרוול, מרחקים מקבועות רטובות ומהבריכה.
- כתב כמויות.
