# אימות – ריצוף בריכה וקופינג (13.11.2026)

**מה נבנה:** בסדנת הריצוף (מצב "ריצוף" / "נתונים ← סדנת ריצוף") נוסף פרק **"בריכה – ריצוף וקופינג"**. אפשר לבחור בו אריח (פסיפס זכוכית 2.5 / 5, פורצלן 12.5×25 / 30×60 / 60×120), צבע לרצפה, צבע לקירות וצבע למדרגות, פס סימון בשפת המדרגות, ורזרבה. לקופינג בוחרים חומר, אורך יחידה, עובי, בליטה לבריכה, פוגה ושפה (מעוגלת או ישרה). השינויים מוצגים במודל ומחשבים כמויות. הבחירה נשמרת במסד הארטיפקט (collection `tiling`, מסמך `pool`). היא נכנסת גם לייצוא ה-Excel של הסדנה (גיליון "בריכה"). שכבות: "בריכה: ריצוף", "בריכה: קופינג" (שכבות רצפה).

**קוד ונתונים:** `tools/finishes/derive_pool_finish.py` ← `data/structure/pool.json` → `data/finishes/pool/surfaces.json` (משטחים). `data/finishes/pool/catalog.json` (אפשרויות, זמני). `data/finishes/pool/layout.json` (הבחירה בריפו). הציור והפאנל: `src/tiling/pool.js`. בדיקה: `tests/tiling.mjs` (בתוך `npm test`).

הבדיקה האוטומטית (`tests/tiling.mjs`, מחשב וטלפון) בודקת את הדברים הבאים:
- 5 רכיבים מצוירים ונראים.
- שטח הקירות = היקף × גובה − החלק המוסתר.
- סה"כ = רצפה + קירות + מדרגות.
- אורך הקופינג = סכום הצלעות (±2 מ"מ) ואף יחידה לא ארוכה מאורך המלאי.
- החלפת אריח וקופינג בונה מחדש את המודל בלי שגיאות בקונסול.
