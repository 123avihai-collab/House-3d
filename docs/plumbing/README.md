# שכבת אינסטלציה (ענף `plumbing`)

מודול נפרד שמציג את תוכנית יועץ האינסטלציה בתלת-ממד, באותן קואורדינטות ומפלסים של המודל הראשי.

## מה בשכבה

- **ביוב** – 6 שוחות ותא שאיבה מחוליות טרומיות, כולל:
  - בסיס עם תעלה (benching), חוליות ותקרה.
  - טבעות הגבהה, מסגרת ומכסה ב.י.
  - אטם שוחה בכל כניסה, ומדרכי רגל מעומק 1.25 מ'.

  הצנרת היא PVC SN-8 ו-HDPE עם:
  - קשתות. זווית 90° בנויה מ-2×45°, לפי הערה 4 של היועץ.
  - מופות ואטמים, ומצמדי ריתוך חשמלי.
  - קולטנים צ.א 1–6 עד הגג, עם ההסטות וכובע אוורור.
  - ק.ב, ק.ב.נ, מ.ר, מ.ת וזנבות לקבועות.
- **סניקה** – מתא השאיבה PC-1: עלייה, "גמל" וקו לשוחה 2.
- **מי גשם** – נקזי גג, צמ"ג 4" (מהרקע האדריכלי) ובור חלחול.
- **מים קרים** – מערכת מדידה (לפי הפרט: בגומחה, ציר המונה 0.60 מעל הקרקע), קו ראשי והסתעפויות עם הקטרים שבתוכנית (ø32/25/20/16), ברזי גן, ברז מילוי בריכה ועולים. **מים חמים** – דוד ומחלק בגג.
- **ממצאי בדיקה הנדסית** – סמן בכל ממצא, עם הסבר והצעה. כולל בדיקה מול דוח הקרקע (11.6, 11.7) ומול התקרות התלויות (K-21). אף הצעה לא בוצעה בתצוגת היועץ.

## הצעת תכנון (לאישור)

במצב **"עם ההצעה"** (שכבות → אינסטלציה → תצוגה) מוצגים, במקום הפריטים של היועץ שהם מחליפים:
- פיר אינסטלציה מצפון לממ"ד.
- 4 מחלקים (קרקע, קומה א', יחידה 1, יחידה 2) עם ברז לכל יציאה.
- PEX בשרוול לכל נקודה, ובכל נקודה זווית קיר וברז זווית בגובה טיפוסי.
- אספקה חמה וקו סחרור מבודדים מהדוד.
- 6 קולטנים מוזזים מתוך הבטון.
- סימון בכל מעבר בקיר ובתקרה.
- **בפיתוח** (`tools/plumbing/propose_site.py`):
  - שוחות 2 ו-3 – מכסה במפלס הפיתוח (הרכב חוליות וטבעות הגבהה חדש).
  - 3 מפלים חיצוניים בכניסות לשוחה 1.
  - הזנה לגלגלון הכיבוי לפי פרט עמדת הכיבוי, והגלגלון מוזז מעל שוחה 2.
  - קטעי חיבור בין קצה הכנת התאגיד (UT-W), מערכת המדידה ותחילת הקו הראשי.
- **מי גשם לא בהצעה** – החלטה PR1: בור החלחול של היועץ סותר את דוח הקרקע, ואין במגרש מקום שעומד בו.

הפירוט המלא: [03-proposal.md](03-proposal.md). הקוד: `tools/plumbing/propose.py` (קלטים ב-`proposal-inputs.json`), והדוח: `tools/plumbing/report_proposal.py`.

## שימוש

לשונית "שכבות" → קבוצת "אינסטלציה – תוכנית היועץ":
- הדלקה וכיבוי לכל מערכת.
- סינון לפי קומה.
- רנטגן (קרקע שקופה).
- סינון ממצאים לפי חומרה, ורשימת ממצאים שמעבירה לממצא.

לחיצה על כל צינור או אביזר מציגה: סוג, קוטר, חומר, מפלס תחתית בהתחלה ובסוף, שיפוע, מאיפה לאן, אביזרים בקטע, מעמד הנתון והמקור.

## צינור הנתונים

```bash
python3 tools/plumbing/extract.py    # קריאת המקורות -> tools/plumbing/cache/raw.json
python3 tools/plumbing/build.py      # רשת, מפלסים, קטרים, ממצאים -> data/plumbing/network.json
python3 tools/plumbing/verify.py     # טבלת אימות -> docs/verification/plumbing-1.md
python3 tools/plumbing/propose.py    # הצעת תכנון -> data/plumbing/proposal.json (כולל propose_site.py)
python3 tools/plumbing/propose_site.py  # רק הצעות הפיתוח -> המפתח site ב-proposal.json
python3 tools/plumbing/report_proposal.py  # -> docs/plumbing/03-proposal.md
python3 tools/plumbing/debug_plot.py ground out.png   # תמונת בדיקה של הרשת (לא חלק מהמודל)
```

- `tools/plumbing/georef.py` – מיקום ה-DXF וה-PDF ב-ITM, באותה שרשרת של המודל הראשי.
- `tools/plumbing/manual-readings.json` – קריאות ידניות מתועדות: מה כל קצה קו (לפי תווית בתוכנית), וכללי מפלס זמניים.
- `data/plumbing/catalog.json` – רכיבים סטנדרטיים בשוק (לאימות מול ספק).
- `data/plumbing/display.json` – קבועי תצוגה.

## חיבור לאתר (הדבר היחיד ששונה בקבצים קיימים)

| קובץ | מה נוסף |
|---|---|
| `js/main.js` | import + `buildPlumbing(ctx)` + `plumbing.attach(app)` (3 שורות) |
| `js/ui/ui.js` | שורה אחת: פאנל של מודול לפי מזהה הקבוצה |
| `data/manifest.json` | 3 קובצי נתונים |

קבוצת השכבות נוספת בזיכרון, כך ש-`data/config/layers.json` לא נערך. התצוגה הקודמת של הביוב (שלב 2ב) כבויה כברירת מחדל, ונשארת זמינה בפאנל השכבות.
