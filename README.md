# House-3d — מגרש 5187, שכונת רקפות, באר שבע

מודל תלת-ממדי מדויק של הבית ושל המגרש. אתר סטטי (Three.js) שעובד גם בטלפון.
כל מידה במודל נגזרת מקבצי המקור בלבד. ראו [CLAUDE.md](CLAUDE.md) (חוקי הפרויקט) ו-[sources/README.md](sources/README.md).

**שלב נוכחי: 3 – שלד לפי תוכניות הקונסטרוקטור (K-11…K-43, K-400): מרתף, קומת קרקע, קומה א', גג ופרגולות, חומות, מדרגות ופילר; 24 שלבי בנייה; ביקורת ברזל. חלונות ודלתות – בהמתנה** (אושר 07.11.2026; עד IFC). אימות: [שלב 1](docs/verification/stage-1.md) · [שלב 2](docs/verification/stage-2.md) · [שלב 2ב](docs/verification/stage-2b.md) · [שלב 3](docs/verification/stage-3.md) · [סביבה](docs/verification/environment.md) · שאלות פתוחות: [docs/open-issues.md](docs/open-issues.md)

## הרצה

```bash
npm run serve          # http://localhost:8080
npm test               # בדיקת נתונים + בדיקת דפדפן headless (מחשב וטלפון), נכשלת על כל שגיאה בקונסול
npm run extract        # חילוץ מחדש מקבצי המקור (דורש את sources/ ו-tools/cache, ראו sources/README.md)
node tools/verify_stage1.mjs   # טבלת אימות שלב 1
node tools/verify_stage2.mjs   # טבלת אימות שלב 2 (חפירה + כלונסאות)
python3 tools/environment/extract_environment.py   # סביבה: מגרשים שכנים, רחובות, מעטפות -> data/environment/
python3 tools/environment/extract_sheet04.py       # גיליון 04 סרוק: בית/חניה/כניסה לכל שכן -> data/environment/sheet04.json (אחריו להריץ שוב extract_environment)
python3 tools/environment/derive_details.py        # בינוי ופיתוח מפורטים -> data/environment/details.json
python3 tools/environment/verify_environment.py    # טבלת אימות סביבה -> docs/verification/environment.md
python3 tools/verify_stage2b.py # טבלת אימות שלב 2ב (קורות, רצפות, קירות מרתף)
```

**תגיות:** כל רכיב רשום ב-`registry` עם `floor` (מגרש/יחידת דיור/קרקע/קומה א'/גג), `system` (שלד, קירות, גמרים, אינסטלציה, מים, ביוב, ניקוז, חשמל, מיזוג, פיתוח, סביבה), `stage` (מצב קיים → חפירה → כלונסאות → קורות יסוד → רצפה → קירות → תקרה → גמרים → ריהוט) ו-`layer`. הנראות של כל רכיב נגזרת מהתגיות ומההגדרות. הגדרות התגיות: `data/config/tags.json`.

**קואורדינטות:** סצנה `x = E−E0`, `y = H−H0`, `z = −(N−N0)`. E0/N0 הם מרכז המגרש מעוגל, ו-H0 = ‏±0.00 = ‏280.50 (‏`data/site/origin.json`). צפון אמיתי = צפון רשת + 0.217°.

### סרגל שלבי הבנייה

הסרגל עובר על 24 צעדי בנייה (`data/config/tags.json` → `sequence`): מצב קיים ← כלונסאות חוץ ← חפירה ← כלונסאות מרתף ← קורות מרתף ← רצפת מרתף ← קירות מרתף ← מילוי חוזר ← צנרת ותעלות ← רצפת קרקע ← קירות קרקע ← תקרת קרקע ← קירות קומה א' ← תקרת גג ← מעקות ← קורות גג ← יסודות חומות ← חומות ← ביוב חוץ ← קורות חוץ ← רצפות חוץ ← פיתוח ← גמרים ← הכול. רכיב מוצג מהצעד שמכיל את {קומה, שלב} שלו (הגדרה עם קומה גוברת על הגדרה כללית) או מהצעד המפורש בתגית `step`. ‹ › ורשימה לקפיצה; `npm test` בודק ששום קיר / עמוד לא מופיע לפני מה שהוא עומד עליו. פירוט: [docs/audit-2026-11-07.md](docs/audit-2026-11-07.md).

כללי "על מה זה יושב" (הערות ק12–ק16, `tools/extract_floor.py`, `tools/extract_openings.py`):
- **קצה קורה בלי תמיכה (K-31 / K-41):** הקצה מוארך עד הפאה הרחוקה של הקורה הניצבת שלפניו, או של הקיר / העמוד שבקו הקורה, עד 1.2 מ'. ההארכה נעשית רק אם המוטות בגיליון הברזל מגיעים לשם.
- **עמוד שהרצפה מתחתיו הוצאה:** העמוד יוצק עם הקורות שנכנסות אליו, מתחתיתן. כך C10, שנמצא בשפת החצר האנגלית.
- **מתחת לרצפת הקרקע ולקורות K-21 שמחוץ למרתף:** בטון רזה 5 ס"מ ומעליו ארגזי פוליביד 25 ס"מ. המידות מ-`excavation.json`, והשכבה היא `underSlabFormers`.
- **חלון ודלת הממ"ד:**
  - הפתח בבטון הוא הרווח בין הקירות ב-K-21: ‏0.99 מ' בחלון (כולל כיס תריס ההדף 0.34) ו-0.80 מ' בדלת. משפחת Revit רחבה יותר.
  - משקופי הפלדה נוצקים עם הקירות, בשכבה `mamadFrames` בשלב "קירות קרקע". הכנפיים יגיעו עם הגמרים.
- **קיר מקווקו ב-PDF של K-21 שחסר ב-DXF ומחבר קירות:** נוסף. כך GW22, הקיר הדרומי של הממ"ד.
- **שקעים וחריצים בקו הקיר:** נסגרים אם ב-PDF של K-21 הקיר מקווקו ורציף שם.
- **קיר שהונמך לתחתית קורה:** החלק שאין מעליו קורה ממשיך עד תחתית התקרה (ק17).
- **ראשי קירות המרתף בשפות פיר המדרגות, החצרות האנגליות והמדרגות למרתף:** הרצפה נוצקת עליהם (ק4, ק18).
- **בתוך המרתף והחצרות:** הקרקע נשארת בתחתית הבור, מתחת לכל רצפות המרתף, גם כשהרצפה הונמכה (ק18).

### פיצ'רים נוספים שהוספתי

1. **קריאת קואורדינטות חיה:** בסרגל התחתון מוצגים E/N ב-ITM וגובה מוחלט ויחסי ל-±0.00 לכל נקודה מתחת לעכבר או בלחיצה.
2. **"מאיפה הנתון":** בכרטיס של כל רכיב מוצג קובץ המקור והשכבה. ערכים זמניים או חסרים מסומנים באזהרה צהובה.
3. **השוואת קרקע קיימת למתוכננת:** שכבה שקופה של מדידת 2025, נקודות גובה של 2023 ו-2025, וטבלת חפירה ומילוי בפינות (בקובץ האימות).
4. **מבטים שמורים** וקישור עמוק: הכפתור 🔗 מעתיק קישור שכולל את המצלמה, השלב, התאריך והשעה.
5. **צילום מסך PNG** בלחיצה.
