# House-3d — מגרש 5187, שכונת רקפות, באר שבע

מודל תלת-ממדי מדויק של הבית ושל המגרש. אתר סטטי (Three.js) שעובד גם בטלפון.
כל מידה במודל נגזרת מקבצי המקור בלבד. ראו [CLAUDE.md](CLAUDE.md) (חוקי הפרויקט) ו-[sources/README.md](sources/README.md).

**שלב נוכחי: 3 – שלד לפי תוכניות הקונסטרוקטור (K-11…K-43, K-400): מרתף, קומת קרקע, קומה א', גג ופרגולות, חומות, מדרגות ופילר; 24 שלבי בנייה; ביקורת ברזל. חלונות ודלתות – בהמתנה** (אושר 07.11.2026; עד IFC). אימות: [שלב 1](docs/verification/stage-1.md) · [שלב 2](docs/verification/stage-2.md) · [שלב 2ב](docs/verification/stage-2b.md) · [שלב 3](docs/verification/stage-3.md) · [סביבה](docs/verification/environment.md) · [גרם בטון ST2 (OC-3)](docs/verification/stair-st2-concrete.md) · שאלות פתוחות: [docs/open-issues.md](docs/open-issues.md)

## הרצה

```bash
npm run serve          # http://localhost:8080
npm test               # בדיקת נתונים + בדיקת דפדפן headless (מחשב וטלפון), נכשלת על כל שגיאה בקונסול
npm run extract        # חילוץ מחדש מקבצי המקור (דורש את sources/ ו-tools/cache, ראו sources/README.md)
node tools/verify_stage1.mjs   # טבלת אימות שלב 1
node tools/verify_stage2.mjs   # טבלת אימות שלב 2 (חפירה + כלונסאות)
python3 tools/environment/extract_environment.py   # סביבה: מגרשים שכנים, רחובות, מעטפות -> data/environment/
python3 tools/environment/extract_sheet04.py       # גיליון 04 סרוק: בית/חניה/כניסה לכל שכן -> data/environment/sheet04.json (אחריו להריץ שוב extract_environment)
python3 tools/environment/derive_details.py        # בינוי ופיתוח מפורטים -> data/environment/details.json
python3 tools/environment/verify_environment.py    # טבלת אימות סביבה -> docs/verification/environment.md
python3 tools/verify_stage2b.py # טבלת אימות שלב 2ב (קורות, רצפות, קירות מרתף)
python3 tools/extract_mamad.py  # ממ"ד: חלון, דלת הזזה ושרוולים לפי תוכנית האדריכל + החזית המערבית -> data/architecture/mamad.json (אחרי extract_openings.py)
python3 tools/finishes/verify_coverage.py   # טיח סבב 4: עור השלד ברשת 2 ס"מ – חייב 0 לא מכוסות (ב-npm test, --check); מדרגות מעל 2 ס"מ -> docs/verification/plaster-deviations.xlsx; טיח במישור אחד (tools/finishes/flatten.py): 0 נקודות שלד לפני הטיח / בסדק, 0 פינות פתוחות -> docs/verification/plaster-flatten.md
python3 tools/finishes/verify_waterproofing.py   # בדיקת איטום: חדרים רטובים, קירות המרתף -> docs/verification/waterproofing-check.md
python3 tools/plumbing/extract_plan_background.py  # עורך הצנרת: רקע אדריכלי לכל קומה (מה-DXF של היועץ) -> data/plumbing/plan-background.json
python3 tools/plumbing/seed_routes.py              # עורך הצנרת: זריעה חד-פעמית של data/plumbing/routes.json מההצעה (לא דורס עריכות)
python3 tools/plumbing/verify_editor.py            # עורך הצנרת: טבלת אימות -> docs/verification/editor-stage-1.md
node tools/plumbing/editor_findings.mjs            # עורך הצנרת: ממצאי הבדיקות בהצעה -> docs/verification/editor-stage-3-findings.md
```

**תוכניות קונסטרוקציה חיות:** `plans.html` – תוכנית K-400 (יסודות וכלונסאות) על הגיליון המקורי: לחיצה על כלונס / קורה / קיר / יסוד פותחת כרטיס עם הסבר פשוט, סקיצת מבט צד וחתך, מידות ומפלסים, השורה מטבלת הכלונסאות ופירוט ברזל (כמות, קוטר, אורך, ק"ג – אותו חישוב של כתב הכמויות). שכבות, צביעה לפי קוטר / מפלס / עומס / אורך, חיפוש, מדידה, קישור ישיר (`#pile-7`). נתונים: `python3 tools/plans/build_k400.py` → `data/plans/k400.json`. אימות: [docs/verification/plans-k400.md](docs/verification/plans-k400.md). שאר הגיליונות (K-11…K-41) – בשלב הבא. ארטיפקט נפרד: https://claude.ai/artifact/KZGRehkmopAgbxZPqYMBbP

**עורך צנרת דו-ממדי:** `editor.html` – מבט על לפי קומה, רקע אדריכלי, שלד, שכבות הצעה ויועץ. מקור האמת לתוואי: `data/plumbing/routes.json`. פירוט ושלבים: [docs/plumbing/editor.md](docs/plumbing/editor.md).

**תגיות:** כל רכיב רשום ב-`registry` עם `floor` (מגרש/יחידת דיור/קרקע/קומה א'/גג), `system` (שלד, קירות, גמרים, אינסטלציה, מים, ביוב, ניקוז, חשמל, מיזוג, פיתוח, סביבה), `stage` (מצב קיים → חפירה → כלונסאות → קורות יסוד → רצפה → קירות → תקרה → גמרים → ריהוט) ו-`layer`. הנראות של כל רכיב נגזרת מהתגיות ומההגדרות. הגדרות התגיות: `data/config/tags.json`.

**קואורדינטות:** סצנה `x = E−E0`, `y = H−H0`, `z = −(N−N0)`. E0/N0 הם מרכז המגרש מעוגל, ו-H0 = ‏±0.00 = ‏280.50 (‏`data/site/origin.json`). צפון אמיתי = צפון רשת + 0.217°.

7. **הנפשת יום שמש**, וכפתורים קבועים ליום הארוך, ליום הקצר ולשוויון.
8. **מצב ביצועים:** AO וצללים ניתנים לכיבוי, וחשיפה מתכווננת. בטלפון AO כבוי כברירת מחדל.
9. **משקל המודל:** רכיבים קטנים באותו חומר מאוחדים לגוף אחד בכל רכיב (`js/core/compact.js`; קווים עבים לא מאוחדים). שכבות שכבויות בפתיחה (סביבה: רחוב, בתי שכנים, ריהוט רחוב, מעטפות, גיליון 04; נקודות מדידה) נבנות רק כשמדליקים אותן בפעם הראשונה (`registry.defer`). טקסטורות צבע/חספוס/AO ב-WebP.
9. **רשת ITM** (5 מ', תוויות כל 25 מ') וחץ צפון אמיתי.
10. **בדיקות אוטומטיות:** `npm test` בודק את הנתונים (מקור לכל רשומה, אין NaN, הגבול עובר דרך נקודות המדידה) ומריץ את האתר במחשב ובטלפון headless.
