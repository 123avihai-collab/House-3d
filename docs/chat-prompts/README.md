# הנחיות מהצ'אט

התיקייה הזאת היא תיבת דואר בין השיחות בצ'אט (כולל שיחות קוליות) לבין קלוד קוד.

- בשיחת חשיבה בצ'אט מגיעים למסקנה, וקלוד בצ'אט שומר אותה כאן כקובץ.
- הקבצים כאן הם בקשות ומסקנות בלבד. הם לא קוד ולא משנים את המודל.
- קלוד קוד מבצע הנחיה רק כשאביחי מבקש במפורש, למשל: "תקרא את ההנחיה האחרונה ב-docs/chat-prompts ותבצע".
- כל ההנחיות כפופות ל-CLAUDE.md. מידות מגיעות רק מ-`sources/`, גם אם בהנחיה כתוב אחרת.

## שם קובץ

`YYYY-MM-DD-נושא-קצר.md`

## מבנה כל קובץ

- **סטטוס:** חדש / בביצוע / בוצע
- **מה מבקשים**
- **החלטות שכבר נסגרו בשיחה**
- **שאלות פתוחות** (לשאול את אביחי לפני ביצוע)

אחרי ביצוע, קלוד קוד מעדכן את הסטטוס ל"בוצע" ומוסיף שורה עם מה נעשה.
